# Book Save

Book Save is a small Windows app for saving notes and selected text. It uses Rust, GPUI Kit, and a local JSON file.

## Run from the source folder

Open PowerShell in `book-save-app` and run:

```powershell
.\run.ps1
```

To build the release app, run:

```powershell
.\run.ps1 -Command release
```

For end-user installation steps, see [the Windows install guide](../docs/INSTALL_WINDOWS.md).

## Use Book Save

- Type a note and press **Enter** or select **Add**.
- Select **Edit** to change a note.
- Select **Delete** to remove a note.
- Use **All**, **Open**, or **Done** to filter the list.
- Search finds text without matching its letter case.
- Press **Ctrl+N** to focus the note field. Press **Ctrl+F** to focus search.
- Press **Escape** to cancel an edit.

To capture selected text, select text in another app and press Left Shift twice. Book Save sends **Ctrl+C**, reads the selected text, and restores the clipboard. Review the text, then press **Enter** or select **Add** to save it. The shortcut uses physical key input. Some apps, elevated windows, and secure desktops may not support it.

## Background capture

The global shortcut only works while Book Save runs, so the app keeps running after its window closes. Closing the window hides it from the taskbar. Use the Book Save tray icon to open the window or select **Exit** to stop capture. The app shows a **BS** monogram icon on its window, tray, and shortcuts. It starts hidden at sign-in, so capture works before you open the window. A capture opens the window for review. Press **Enter** or select **Add** to save it.

The installer and uninstaller never force-close the app. If Book Save is running, they ask you to select **Exit** from the tray menu first. This lets pending saves finish.

## Saved list

Book Save stores its Windows list in `%LOCALAPPDATA%\Book Save\captures.json`. It creates the file when you save your first note. Each save writes a temporary file before it replaces the previous list. A failed save leaves the old list in place.

The installer copies an older `data\captures.json` file to this location if the new file does not exist. It does not replace an existing user list. Keep a backup if you need one. Book Save does not sync data or merge changes from two running copies.

## Build and check

The Windows build needs Rust 1.99 or later, Visual Studio C++ build tools, a Windows SDK, and CMake. Build a release app before you run the benchmark. Run `.\verify-lifecycle.ps1` to check hidden startup, tray restore, single-instance handover, close, and Exit. It uses temporary app data and does not touch the clipboard. Run `.\verify-clipboard.ps1` to check selected-text capture and clipboard restore behavior. Run `.\bench.ps1 -Runs 7 -IdleSeconds 12` to measure launch readiness, idle CPU, memory, and executable size.

The Windows executable embeds a **BS** monogram icon (`assets\book-save.ico`, generated by `assets\make-icon.ps1` with only built-in .NET drawing) through `assets\book-save.rc` and `build.rs`. No runtime dependency is added; the icon costs about 9 KB in the executable. Re-run `assets\make-icon.ps1` if you change the artwork, then rebuild.
